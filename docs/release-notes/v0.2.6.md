# v0.2.6

## 中文

修复页面数据请求没有结束时，导航永久显示骨架屏的问题。

- 技能导入支持含多个标准 Skill 的 Claude 插件包，完整保留命令、辅助技能和共享资源；hooks、MCP、agents、LSP 不由此适配启用。
- 普通 API GET 请求默认 30 秒超时，并通过 `AbortController` 中止未完成请求；超时会显示错误和重试按钮，响应正文读取也在超时范围内。
- `/api/settings` 的关键数据读取失败时返回 HTTP 500；服务端日志记录请求路径、状态码、失败操作及底层错误，便于定位服务端故障。
- 本次没有新增数据库迁移或 Go 模块依赖变更。

## English

Fix pages remaining on skeletons when a data request never completes.

- Import Claude plugin packages containing multiple standard Skills while preserving commands, helper Skills, and shared resources. This adapter does not enable hooks, MCP, agents, or LSP.
- API GET requests now time out after 30 seconds and abort through `AbortController`. The page shows the error and a retry action; response-body reads are covered by the same deadline.
- Critical `/api/settings` read failures return HTTP 500 and log the request path, status, operation, and underlying error for diagnosis.
- No database migrations or Go module dependencies were added.
