# tidebot v0.1.9

这是一个小版本，只做了一件事：把界面重新设计了一遍。以前的沙色底加白框看久了有点闷，这次换成更干净的石墨风格，同时留了三套主题给你挑。

## 新界面 / New look
- **默认主题「石墨」**：白底、深色主按钮、靛蓝强调色，卡片换成细线分隔的分组，不再框套框。侧栏、设置导航和各处图标保持彩色，一眼能认出来。
  New default theme Graphite: white surfaces, near-black primary buttons, indigo accent, hairline groups instead of nested boxes; icons stay colourful.
- 顶部多了一条标题栏，显示当前页面标题或面包屑；首页改成“数字一览 + 快捷操作 + 各任务最近状态 + 接下来 24 小时”；关于页的链接改成短链接，完整地址在悬停提示里。
  A top bar with the page title or breadcrumb, a reworked home page, short links on the About page.

## 三套主题 / Three themes
- **石墨 / 潮汐 / 午夜**，每套都有浅色和深色，也可以跟随系统。在“设置 → 通用 → 外观”里点色卡切换，选择存在 tidebot 里，换个浏览器打开也一样。
  Graphite, Tide (the old blue-green, calmer) and Midnight (dark-first, amber accent), each light and dark or following the system, in Settings → General → Appearance.
- 打开页面时直接就是你选的主题，不会先白一下再变；桌面版窗口在网页加载前就先涂好主题底色。
  No flash on load; the desktop window is pre-painted with the theme's background.

## 命令面板换主题 / Change theme from the palette
- ⌘K / Ctrl+K 里选「切换主题…」，用方向键移动时整个窗口跟着预览，回车保存，Esc 或点外面就恢复原样。直接输入「深色」「午夜」也能一步切过去。
  ⌘K / Ctrl+K → "Change theme…": arrow keys preview the whole window, Enter keeps it, Esc reverts. Typing "dark" or "midnight" works too.

0.1.8 的 Windows、macOS 桌面版、Linux AppImage 和服务端压缩包会在应用里收到这次更新（`.deb` 和 Docker 跟以前一样只提示）。
Desktop and server-tarball installs of 0.1.8 get this update in-app (.deb and Docker are notify-only, as before).
