# tidebot v0.1.5

## 新东西 / New
- **官方插件**（插件页的卡片墙，一键安装，权限逐项确认）：
  - RSS / Atom 订阅：有新文章就触发任务（ETag/Last-Modified，按 guid 去重），也给 Claude 一个 `fetch_feed` 工具。
  - 网页变化监控：可选 CSS 选择器、变化阈值、忽略空白，遵守 robots.txt。
  - 企业微信、钉钉（加签 HMAC-SHA256）群机器人：发文本 / Markdown，设置里能“发一条测试”。
  - 邮件：SMTP 发信（强制 TLS）+ IMAP 收信触发器（按发件人、主题、关键词过滤）。
  - 每日资讯摘要：一套技能 + 按钮 + 每日任务模板，读 RSS、整理成摘要、发到企业微信 / 钉钉 / 邮件。
  - 插件触发器创建时可以“试一下（不触发）”，先看看会抓到什么。
  - 密钥只放在密钥库里，不会出现在配置或日志里。
  Official plugins: RSS, web monitor, WeCom, DingTalk, Email, and a daily digest pack.
- **AI 创建插件**：用一句话描述 → 确认规格卡片（类型、权限、设置项、语言）→ Claude Code 在隔离的临时目录里生成（受限工具、无网络、预算上限可见、可随时取消）→ 自检（plugin.yaml、启动、握手、触发器/工具枚举、设置表单）→ 你看文件和改动、逐项勾选权限后再安装。之后可以在插件里用对话继续改，每次都是新的不可变版本，随时回滚。权限从不自动授予，密钥不会进入提示词。
  Describe a plugin, let Claude Code build and self-check it in a sandbox, review and approve, then iterate by chat with rollback.
- **会动的 logo**：侧边栏、登录页和启动画面上的浪会慢慢流动；窗口隐藏时暂停，系统开了“减少动态效果”就不动，有会话在跑时流得快一点。纯 SVG + CSS，几乎不占 CPU。图标本身保持静态。
