# tidebot v0.2.2

本次补丁版增加官方「Kilo 免费模型池」插件，修复 Skill 仓库添加弹窗的显示问题，增加公开仓库预设，并减少扫描、安装多文件技能时的 Git 进程开销。

## Kilo 免费模型池

- 从官方插件目录安装「Kilo 免费模型池」，批准 `ai-gateway.kilo.ai` 网络权限，确认上游可能记录提示词和输出并用于训练或改进服务，再刷新列表选择模型。任务中选择服务商 `kilo-free` 即可使用，无需填写上游 API Key。
- 动态目录只接受明确免费、零价且支持工具调用的模型；默认 `kilo-auto/free`。模型不可用时明确报错，不切换到付费服务商。安装操作不改变已有默认服务商或任务，也不自动发送业务内容。
- 本机网关转发 Kilo 原生 Anthropic Messages 与流式事件；访问 token 只在本地使用，不发送到上游。禁用插件或撤销权限后停止网关并阻断后续请求。
- 免费模型受上游额度、地区、可用性和数据政策限制，不能发送个人或机密内容。本插件不复制 OpenCode 的客户端指纹或会话伪装，不提供通用的 OpenCode 免费 API。

[安装、原理与使用限制](https://github.com/Zhengmingming1/tidebot/blob/v0.2.2/docs/free-model-pool.md)

## 显示与操作

- 调整仓库弹窗的标题与帮助信息显示，避免提示内容被裁切或遮住标题。
- Git 地址、分支和扫描目录的说明改为字段下方常显帮助，无需悬停或聚焦提示图标才能阅读。
- 「Skill 仓库」列表增加「内置公开仓库」入口；空列表和已有仓库时都能找到这些来源。

## 内置公开仓库

| 来源 | 预置扫描目录 | 内容 |
|---|---|---|
| [Anthropic Skills](https://github.com/anthropics/skills) | `skills` | 文档、设计、开发与技能创建示例 |
| [OpenAI Plugin Skills](https://github.com/openai/plugins) | `plugins` | 开发与服务插件中的技能示例 |
| [Vercel Agent Skills](https://github.com/vercel-labs/agent-skills) | `skills` | React、Web 界面、部署及工程实践 |

- 点击「一键添加并扫描」即可登记来源并读取技能目录，之后仍需选择技能、预览和安装。打开页面不会自动下载或安装。
- 已有匹配仓库显示浏览入口，重复点击不会重复登记同一预设。扫描失败保留已添加记录，可以从仓库页面重试。
- OpenAI 预设使用当前的 `openai/plugins`；已标记弃用的 `openai/skills` 不作为内置来源。

## 扫描与安装性能

- 用分批 `git cat-file --batch` 读取技能文件，避免每个文件都启动一个 Git 进程。
- 只读操作不再重复遍历缓存目录计算体积；会修改缓存的操作仍检查 256 MiB 限制。
- 继续校验对象身份、类型、大小和输出完整性。此优化减少本地文件读取开销，不代表所有仓库的网络下载或完整任务耗时会按同一比例改善。

## 升级与验证边界

从 v0.2.1 升级没有新增数据库迁移，已有仓库、技能、来源与历史版本继续保留。仓库功能仍需运行 Tidebot 的主机具备 Git 和适用的网络、认证配置。

预设指向真实公开来源，不代表其中所有技能已在 Tidebot 验收。插件级 MCP、目录外资源、脚本环境、第三方服务与授权仍需按技能要求配置；不会随预设添加而自动启用。各技能的许可与运行条件以原仓库内容为准。

免费池已完成上游匿名接口的固定内容验证：OpenAI 与 Anthropic Messages 各一轮工具调用和一轮工具结果回传的 SSE 响应，四次均为 HTTP 200、费用为零。这不等于全部免费模型、真实项目任务或所有 Claude Code 版本的端到端验收；上游不支持的精确 token 计数会明确返回不支持。真实 Claude Code 2.1.280 已通过 Tidebot 任务路径验证 `kilo-auto/free` 和 Liquid 免费模型：两次均成功读取测试文件、回传工具结果并输出正确内容，记账为免费且保留 token 用量。

本地 `go test ./...`、全量 `go test -race -count=1 ./...`、`go vet ./...`、WebUI bundle 与中英词条检查通过。Chrome 已验证官方插件安装、模型目录加载，以及宽屏和窄屏弹窗布局；未运行 WebKit 实机验证。发布流程继续执行完整测试矩阵、三平台打包和更新索引签名，最终结果以本版本对应的 GitHub Actions 与发布附件为准。

## English

This patch fixes the Skill repository dialog layout and shows field help inline. The repository page now includes Anthropic Skills, OpenAI Plugin Skills, and Vercel Agent Skills presets. Add and scan a source with one action, then choose which skills to preview and install. Existing matching repositories can be opened without creating duplicates, and failed scans retain their repository record for retry.

The official Kilo Free Pool plugin adds anonymous access to current zero-priced, tool-capable models. Install it, approve network access, acknowledge the upstream data-use policy, refresh and select a model, then choose `kilo-free` for a task. Native Anthropic Messages and SSE are forwarded through a local authenticated gateway without sending credentials upstream. Existing defaults remain unchanged; there is no paid fallback. Free providers may retain or train on submitted content, and availability and rate limits apply. OpenCode client impersonation is not included.

Git objects are read in bounded batches, and read-only operations no longer repeatedly walk the cache. Existing file validation and cache limits remain. There are no new database migrations from v0.2.1. Public presets are source shortcuts, not a guarantee that every skill or external dependency is ready to run.
