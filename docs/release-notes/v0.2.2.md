# tidebot v0.2.2

本次补丁版修复 Skill 仓库添加弹窗的显示问题，增加公开仓库预设，并减少扫描、安装多文件技能时的 Git 进程开销。

## 显示与操作

- 调整仓库弹窗的标题与帮助信息显示，避免提示内容被裁切或遮住标题。
- Git 地址、分支和扫描目录的说明改为字段下方常显帮助，无需悬停或聚焦提示图标才能阅读。
- 「Skill 仓库」列表增加「内置公开仓库」入口；空列表和已有仓库时都能找到这些来源。

## 内置公开仓库

| 来源 | 预置扫描目录 | 内容 |
|---|---|---|
| [Anthropic Skills](https://github.com/anthropics/skills) | `skills` | 文档、设计、开发与技能创建示例 |
| [OpenAI Plugin Skills](https://github.com/openai/plugins) | `plugins` | 开发与服务插件中的技能示例 |
| [Vercel Agent Skills](https://github.com/vercel-labs/agent-skills) | `skills` | React、Web 界面、部署及工程实践 |

- 点击「一键添加并扫描」即可登记来源并读取技能目录，之后仍需选择技能、预览和安装。打开页面不会自动下载或安装。
- 已有匹配仓库显示浏览入口，重复点击不会重复登记同一预设。扫描失败保留已添加记录，可以从仓库页面重试。
- OpenAI 预设使用当前的 `openai/plugins`；已标记弃用的 `openai/skills` 不作为内置来源。

## 扫描与安装性能

- 用分批 `git cat-file --batch` 读取技能文件，避免每个文件都启动一个 Git 进程。
- 只读操作不再重复遍历缓存目录计算体积；会修改缓存的操作仍检查 256 MiB 限制。
- 继续校验对象身份、类型、大小和输出完整性。此优化减少本地文件读取开销，不代表所有仓库的网络下载或完整任务耗时会按同一比例改善。

## 升级与验证边界

从 v0.2.1 升级没有新增数据库迁移，已有仓库、技能、来源与历史版本继续保留。仓库功能仍需运行 Tidebot 的主机具备 Git 和适用的网络、认证配置。

预设指向真实公开来源，不代表其中所有技能已在 Tidebot 验收。插件级 MCP、目录外资源、脚本环境、第三方服务与授权仍需按技能要求配置；不会随预设添加而自动启用。各技能的许可与运行条件以原仓库内容为准。

发布流程继续执行完整测试矩阵、三平台打包和更新索引签名；最终结果以本版本对应的 GitHub Actions 与发布附件为准。

## English

This patch fixes the Skill repository dialog layout and shows field help inline. The repository page now includes Anthropic Skills, OpenAI Plugin Skills, and Vercel Agent Skills presets. Add and scan a source with one action, then choose which skills to preview and install. Existing matching repositories can be opened without creating duplicates, and failed scans retain their repository record for retry.

Git objects are read in bounded batches, and read-only operations no longer repeatedly walk the cache. Existing file validation and cache limits remain. There are no new database migrations from v0.2.1. Public presets are source shortcuts, not a guarantee that every skill or external dependency is ready to run.
