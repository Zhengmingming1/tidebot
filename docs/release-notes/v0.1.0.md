First tagged build. It is early software maintained by one person; expect rough edges.

## What's in it

- Scheduler for Claude Code tasks: cron, manual runs, concurrency limit, timeouts, retry with
  backoff, a circuit breaker after 3 failures, catch-up after downtime (skip / once / all) and overlap rules.
- Versioned tasks and skills with rollback; plain-language requirement changes confirmed as a
  batch; periodic consolidation of accumulated requirements.
- Skill optimization with off / suggest / canary modes and automatic withdrawal of a bad canary.
- Daily spend caps (global / task / bucket), reset at local midnight.
- Execution guard: per-task workspace, tool allow-lists, a PreToolUse hook that blocks dangerous
  commands until you confirm, and wrapping of external input (webhook, email, files) as data.
- Plugins as separate processes (JSON-RPC over stdio) with versioned installs and per-item
  permission approval; MCP connectors; webhook (token or HMAC), file-change, email and IM triggers;
  workflow pack import/export.
- Notifications (email, webhook, Feishu, DingTalk, WeCom, Telegram) with quiet hours and a digest.
- Backups (`.agentbak`, secrets only with a passphrase), log/artifact retention, a dashboard and a
  Prometheus `/metrics` endpoint, sandbox dry-runs, self-update with checksum verification.
- WebUI in English and Chinese; an experimental desktop app (tray + window).

## Known gaps

- Only the Linux builds have been run by hand. The macOS .dmg and Windows installer are built
  and packaged in CI but nobody has clicked through them yet.
- Builds are unsigned unless signing secrets are configured.
- The AppImage relies on the system's WebKitGTK 4.1.
- Plugin CPU limits are not enforced; memory is capped with rlimit on Linux only.
