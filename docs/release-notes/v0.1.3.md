## What's new in v0.1.3

- **Self-update.** tidebot now checks once a day for a new signed release (Settings → About → Updates, can be turned off). "Update" downloads it, checks the ed25519 signature and sha256, swaps the files, restarts, and rolls back on its own if the new version doesn't come up. Docker / .deb / Homebrew installs just get a notice. `agentctl update check|apply` from the shell. No telemetry.
- **Claude Code status** in the sidebar: version, login, last provider test, running sessions with memory (now on macOS and Windows too, including node child processes).
- **Compact home dashboard** that fits one screen at 1440×900.
- **Notifications follow your language**: stored as message + parameters and shown in zh-CN or English, whichever you use.
- **2FA secret encrypted at rest** (existing setups are migrated on first start).

From this version on, updates come from the public [tidebot-releases](https://github.com/Zhengmingming1/tidebot-releases) repo. v0.1.2 and older have no updater, so install v0.1.3 once by hand.

## v0.1.3 更新内容

- **自动更新**：每天检查一次新的签名版本（设置 → 关于 → 更新，可关闭）。点“更新”会下载、校验 ed25519 签名和 sha256、替换文件、重启；新版本起不来会自动回滚。Docker / .deb / Homebrew 安装只提示。命令行：`agentctl update check|apply`。不上报任何数据。
- 侧边栏 **Claude Code 状态**卡片：版本、登录、上次连接测试、运行中的会话和内存（现在 macOS、Windows 也有，含 node 子进程）。
- **首页更紧凑**，1440×900 一屏放下。
- **通知跟随界面语言**：按消息键 + 参数存储，中英文各自显示。
- **两步验证密钥加密存储**（已有设置在首次启动时自动迁移）。

从这个版本开始，更新从公开仓库 tidebot-releases 下载。v0.1.2 及更早版本没有更新器，需要手动装一次 v0.1.3。
