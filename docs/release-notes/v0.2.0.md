# tidebot v0.2.0

本次为功能次版本：新增技能组合、可视化拖拽工作流和 AI 依赖检测，并改进技能导入兼容性。

## 新增能力

- **技能组合**：选择一个主技能与多个辅助技能，在同一次运行中协作；支持保存组合、固定版本及 ZIP 导入导出。任务编辑、试跑、重跑和任务导出会保留完整绑定。
- **拖拽设计器**：将技能或组合拖入画布，移动节点、拖线连接，在侧栏编辑提示词、输入引用和前置依赖。布局与流程版本一起保存，支持自动排列和缩放。
- **条件与并行**：支持六种文本条件、满足/不满足两个出口、并行处理及明确的汇合规则。下游通过 `{{input}}` 和 `{{steps.步骤ID.output}}` 使用输入及上游结果。
- **运行记录**：启动时固定流程与全部技能版本，保留每步状态、输出及子运行日志；失败停止后续执行，取消会传递到排队和运行中的步骤。
- **依赖检测**：任务、快捷运行、按钮、技能组合和工作流可发起 AI 静态分析，区分系统确认的缺失项与模型推断的待核实项。分析不安装依赖、不执行目标任务、不读取凭据文件。

## 修复与兼容

- 支持从标准 `skills/<名称>/SKILL.md` 插件包及其外层下载目录导入技能；多个候选会明确提示。
- 修复导入预览被迟到响应覆盖、窄窗口弹窗裁切，以及工作流保存等待期间继续编辑导致的草稿丢失。
- 临时技能副本的命令名与实际调用保持一致，原技能内容不变；长工作流输入通过 stdin 传递，避免命令行长度限制。
- 原有单技能任务、历史版本和配置继续保留。首次启动自动新增技能组合、运行绑定快照与工作流数据表（迁移 028、029）。
- 升级前建议保留应用备份。旧版不识别新工作流，编辑新多技能任务可能丢失辅助绑定；需要降级时使用升级前备份，二进制回滚不会自动回滚数据库。

## 首版边界与验证

- 每个组合最多 16 个技能；每个工作流最多 32 步、最多 4 步并行，仍受全局并发和预算约束。
- 工作流目前手动触发，每步使用独立目录，内置文件工具只读；已批准的 MCP 连接器沿用现有授权。
- 中断保留已完成结果并标记状态，不自动重试、续跑或重放可能产生副作用的步骤。
- 核心与桌面测试、静态检查、关键并发测试及三平台 CI 通过；本地浏览器已验证拖拽、连线、保存、分支、并行汇合和依赖报告。
- 执行链路和 AI 报告使用模拟执行器验证，真实模型与外部服务尚未作端到端验收。

## English

This minor release adds reusable skill sets, a visual workflow canvas, and AI dependency checks.

Combine one primary skill with supporting skills, pin their versions, and transfer sets as ZIP packages. Drag skills or sets onto the canvas, connect conditional and parallel steps, and pass upstream results into downstream prompts. Each execution records an immutable workflow and skill-version snapshot with per-step outputs and child-run logs.

Dependency checks analyze supplied task and skill material without running the target task or installing packages. Confirmed missing references remain distinct from unverified AI inferences. Standard plugin-wrapped skills now import correctly, and stale upload responses and narrow-window clipping are fixed.

Existing tasks and versions remain intact; additive database migrations run at startup. Workflows are manually triggered, with isolated local read-only directories and existing approved MCP permissions. Interrupted runs are not replayed automatically. Core/desktop tests, three-platform CI, and local browser checks pass; model execution and dependency-report validation used mocks.
