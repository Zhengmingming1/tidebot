# v0.2.8

## 中文

### 新增
- 先跑通再加限制：选技能开会话，在会话里改技能草稿、试跑、手动采用，再「存为任务」（锁定采用的版本）
- 运行、任务、会话、工作流可选只读 / 可修改 / 可执行命令，可执行命令在系统沙箱里跑；Windows 无系统沙箱，会标出并首次说明
- 工作流可选目录、权限和总预算，也能作为任务目标定时运行
- 「设置 › 安全」显示沙箱状态；运行改动了 agent 配置时提示

### 优化
- 去掉每次运行 $0.05、30 分钟和会话 50 轮的隐藏默认限制，只保留全局每日预算；老任务没改过的 $0.05 可在花费页一键恢复
- 技能导入和扩展安装共用风险扫描，低风险直接导入；自动分析和灰度默认关闭，收进「进阶」
- 工作流执行记录、软删版本和会话转录纳入数据清理
- 多处统计和检查移出数据库事务；会话和提议轮询没变化时不再整份重拉；卸载能力包更快
- 升级 SQLite 驱动，修复取消查询导致 WAL 无限增长

### 修复
- 会话里确认卸载带技能的能力包必然失败
- 会话回答被强退后，下一轮回答丢失、那一轮花费漏算
- 删掉的会话留下目录和草稿，且误报删除失败
- 扩展操作失败留下空会话；设备登录失败后无法重试
- 中断的依赖安装残留占满配额；Windows 清理旧快照中途停止
- 会话文件搜索漏掉超长行之后的内容，截断时乱码
- 工作流总时长填 0 一启动就超时

## English

### Added
- Run first, limit later: chat with a skill, edit its draft in the session, try it, adopt it by hand, then Save as task (pinned to the adopted version)
- Read-only / can edit / can run commands for runs, tasks, sessions and workflows; commands run in an OS sandbox (Windows has none and says so)
- Workflows get a folder, permission level and total budget, and can be scheduled as a task target
- Settings › Security shows sandbox status; runs that changed agent config are flagged

### Improved
- Removed the hidden $0.05 per-run, 30-minute and 50-turn defaults; only the global daily budget remains (old defaults restorable from Spend)
- Skill import and extension installs share one risk scan; auto-analysis and canary are off by default under Advanced
- Workflow runs, deleted workflow versions and session transcripts are now cleaned up
- Less work inside database transactions, lighter polling, faster package uninstall
- SQLite driver upgrade fixes unbounded WAL growth

### Fixed
- Uninstalling a package with skills from a session always failed
- After a forced quit mid-answer, the next turn was lost and the turn's cost was missing
- Deleted sessions left folders and drafts behind and reported a false failure
- Empty sessions after failed extension actions; device login couldn't be retried
- Interrupted dependency installs filled the quota; Windows snapshot cleanup stopped midway
- Session file search missed text after very long lines and garbled truncation
- A workflow total time of 0 timed out immediately
