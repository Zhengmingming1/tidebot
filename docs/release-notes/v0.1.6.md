# tidebot v0.1.6

## 修复 / Fixes
- **国内检查更新超时**：之前只认 `HTTPS_PROXY` 环境变量，而 macOS / Windows 上从图形界面打开的 App 拿不到它，所以开着代理也会直连 GitHub 然后超时。现在会自动读取系统代理（macOS `scutil`、Windows 注册表、Linux 环境变量 / gsettings）。
  Update checks now use your system proxy; GUI apps never saw HTTPS_PROXY before.
- 关于页、README 和安装包里不再出现私有源码仓库的链接（对用户是 404），统一指向公开的发布页。
  No more links to the private source repo; everything points at the public releases page.

## 新东西 / New
- **设置 → 网络**：代理可选 自动 / 系统、手动（http / https / socks5）、关闭，带“测试”按钮。检查更新、测试服务商、插件和 Claude Code 都走这里。优先级：手动设置 > 环境变量 > 系统代理。
- **更新下载镜像**（默认不启用）：GitHub 连不上时按顺序换镜像。更新清单有签名、安装包校验 sha256，镜像改不了内容。
- 更新失败时会说清楚是超时、DNS、TLS、代理、404 还是签名问题，并给出怎么修和“手动下载”链接。

还在用 0.1.3–0.1.5 又连不上 GitHub 的话：到 https://github.com/Zhengmingming1/tidebot-releases/releases/latest 手动下载这一版，以后就能自动更新了。
