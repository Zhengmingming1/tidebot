# v0.2.9

## 中文

### 新增
- 运行、任务和会话改了用户目录里的文件会记下来，运行页和会话轮次卡片可查看，预检后撤销
- 运行对话框和会话输入框可选推理强度，重跑、存为任务都会带上
- 任务页列出它启动的工作流运行，工作流运行标出来源任务
- 设置 › 数据可配工作流运行保留天数，立即清理前列出将删除的记录
- 换机恢复后列出工作目录不存在的任务和工作流，提示一次

### 优化
- 存储清理、卸载能力包、扫描技能仓库更快，不再长时间占着数据库写锁
- 数据用量计入会话、Claude Code 转录、扩展、技能仓库和临时目录
- 报错、限流提示和依赖检查报告按界面语言显示
- 会话每轮显示实际用的提供商、模型和推理强度；从未用过的空会话过期自动清理
- WebUI 资源体积更小

### 修复
- 预算录取、费用和花费写入失败会重试，不再跳过运行或卡住后续运行
- 任务、技能、组合保存中途失败不再留下半截数据；采用或转正技能前确认版本是否已变
- 同一目录不再被任务、会话、工作流同时改；定时运行等待时不再堆积连跑
- 换机恢复正确改写旧路径（中文 home、Windows 短路径、JSON 里的路径）
- 设置 › 关于的更新说明显示纯文本，不再露出 Markdown 标记
- 撤销改动和会话记账遇到失败或数据库忙会重试，不再报假冲突或丢轮次

## English

### Added
- Files changed in your folders by runs, tasks and sessions are recorded; review and revert them (with a pre-check) from the run page or session turn cards
- Pick reasoning effort in the run dialog and session composer; reruns and Save as task keep it
- The task page lists workflow runs it started; workflow runs show their source task
- Settings › Data: workflow run retention days, and Clean now lists what it will delete
- After restoring on another machine, tasks and workflows with a missing folder are listed once

### Improved
- Faster storage cleanup, package uninstall and skill-repo scans, without long database write locks
- Data usage now counts sessions, Claude Code transcripts, extensions, skill repos and temp folders
- Errors, rate-limit messages and dependency reports follow the UI language
- Session turns show the provider, model and effort actually used; never-used empty sessions expire
- Smaller WebUI assets

### Fixed
- Budget admission, cost-policy and spend writes retry instead of skipping or blocking runs
- A failed save no longer leaves half-written tasks, skills or compositions; adopting or promoting a skill asks if the version changed
- Tasks, sessions and workflows no longer edit the same folder at once; waiting scheduled runs don't pile up
- Restore rewrites old paths correctly (Chinese home, Windows short paths, paths inside JSON)
- Settings › About shows update notes as plain text, not raw Markdown
- Reverts and session accounting retry on failure or a busy database, with no false conflicts or lost turns
