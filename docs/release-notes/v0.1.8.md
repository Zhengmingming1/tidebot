# tidebot v0.1.8

这一周主要在补“每天都在用”的那些地方：任务多了怎么找、跑完的结果怎么看、通知别太吵，顺手修了两个定时相关的老 bug。

## macOS 0.1.7 用户请先看 / macOS users on 0.1.7, read this first

0.1.7 的 macOS 桌面版里，“更新”按钮点了没反应（WKWebView 不支持 `window.confirm()`，这版已经换成应用内的确认框）。所以这一次需要手动装一下：

1. 点菜单栏的 tidebot 图标 → 退出；
2. 下载 [tidebot-desktop-macOS-AppleSilicon-Intel.dmg](https://github.com/Zhengmingming1/tidebot-releases/releases/latest/download/tidebot-desktop-macOS-AppleSilicon-Intel.dmg)，把 tidebot.app 拖进“应用程序”，替换旧的；
3. 第一次打开时右键 → 打开，或者在终端执行 `xattr -dr com.apple.quarantine /Applications/tidebot.app`。

数据都在原来的位置，不受影响。从 0.1.8 开始，以后的版本在应用里点“更新”就行。Windows 桌面版、Linux AppImage 和服务端压缩包的 0.1.7 不受影响，在应用里照常更新（`.deb` 和 Docker 跟以前一样只提示，用包管理器或拉新镜像升级）。

The "Update" button in the macOS desktop build of 0.1.7 does nothing (WKWebView ignores `window.confirm()`; this release uses an in-app dialog instead). Please install 0.1.8 by hand once: quit tidebot from the menu bar icon, replace tidebot.app in Applications with the one from the .dmg, and open it the first time with right-click → Open (or `xattr -dr com.apple.quarantine /Applications/tidebot.app`). Your data stays where it is, and later versions update in-app again. Windows, AppImage and server-tarball installs of 0.1.7 update in-app as usual (.deb and Docker are notify-only, as before).

## 运行结果 / Run results
- **最终回答单独显示**：运行详情页多了一张“最终回答”卡片，Markdown 按排版显示，可以切到源码、复制、下载成 .md。以前只能在日志里看被截成一行的 400 字。
  Run details show the agent's full final answer, rendered as Markdown, with copy and download.
- **和上次比一比**：回答可以和这个任务上一次成功的回答逐行对比，改了哪些字会标出来；完全一样时显示“与上次相同”。
  Diff the answer against the task's previous successful run; identical answers are marked.
- 通知里带上回答的开头几行（飞书、钉钉、企业微信、Telegram、Webhook、通知中心），邮件带完整回答；还可以设成“只在回答有变化时通知”，天天一样的日报就不来烦你了。
  Notifications include the start of the answer, and can be sent only when the answer changed.
- 运行列表可以按时间筛（今天、昨天、最近 7/30 天或自选日期），搜索结果直接显示命中的那一段，筛选旁边有数量，超过 200 条可以加载更多，还能把当前筛选结果导出成 CSV 或 JSONL。
  Runs: date filters, search snippets, counts, load more, CSV/JSONL export.

## 任务 / Tasks
- **标签**：任务可以加标签，列表按标签筛选，批量加/删标签；花费页也能按标签看。
  Task tags, with filtering, bulk edit and spend by tag.
- 任务列表每行显示最近 10 次运行的色块，新增“失败中”筛选；`j`/`k` 上下选行，回车打开，`r` 立即运行。
  Last 10 runs per task, a "failing" filter, and keyboard row navigation.
- **暂停**：可以一键暂停全部定时，也可以单独暂停某个任务 1 小时、4 小时或到明天 9 点，到点自动恢复。被自动暂停的任务会写明原因（连续失败、预算用完……）。
  Pause all schedules or one task for a while; auto-paused tasks say why.
- 任务表单里可以直接设失败重试、错过的运行怎么补、工作文件夹（桌面版能用系统对话框选）、优先级。
  Retry, missed-run, working folder and priority settings in the task form.
- 任务可以导出成 JSON、再导入（导入前逐条预览，默认暂停），不含密钥和运行记录。
  Export / import tasks as JSON with a preview.

## 定时 / Scheduling
- **修了一个比较严重的 bug**：定时任务第一次运行之后，下一次时间会按 UTC 算，上海时区 9:00 的任务从第二次起变成了 17:00。现在统一按调度时区算，启动时会自动把存错的时间改回来。
  Fixed: after the first run, schedules were computed in UTC (a 9:00 Shanghai task moved to 17:00). Existing schedules are corrected on start.
- 夏令时切换当天不再漏跑或重跑；“设置 → 通用”里可以搜索、修改调度时区，马上生效。
  DST-safe schedules; the scheduling timezone can be changed in Settings → General.
- 笔记本用电池时可以推迟不急的任务；磁盘快满（默认低于 500 MB）时不启动新运行，腾出空间后自动恢复。
  Defer low-priority runs on battery; don't start runs when the disk is nearly full.

## 花费 / Spend
- 同时跑的几个运行共享剩余预算，开始前先预留，不会一起冲过上限；花费页用斜纹显示预留部分。
  Concurrent runs reserve from the remaining budget instead of all overshooting it.
- 预算每项一行，上限可以就地改；修了在设置页改上限会把“超出后”“提醒阈值”重置的问题。每日柱状图可以点选某一天看明细。
  Inline budget edits (and a fix for settings being reset), click a day in the chart.

## 设置和安全 / Settings & security
- 通知渠道可以直接在设置页加（飞书、钉钉、企业微信、Telegram、邮件、Webhook），粘贴地址自动识别类型，保存前能发测试；每个渠道显示最近一次发送结果，连续失败 3 次会提醒。
  Add notification channels in Settings, with test send, last delivery status and failure alerts.
- 模型接入可以“获取模型列表”，从服务商那里拉可选模型，不用自己背型号。
  Fetch the provider's model list when adding a model.
- 能在设置页改密码、查看并退出其他已登录的设备；两步验证码只能用一次。
  Change password, see and sign out other devices; one-time 2FA codes.

## 界面和性能 / UI & performance
- 技能可以浏览任意版本的文件，Markdown 按排版显示。
  Browse any skill version's files, with Markdown preview.
- 快捷键按系统显示（Mac 上 ⌘K、⌘Enter），弹窗里任意输入框按 ⌘/Ctrl+Enter 就是点主按钮。
  Platform-aware shortcuts; ⌘/Ctrl+Enter submits dialogs.
- 连不上 tidebot 时底部提示并自动重连，恢复后原地刷新，不再跳回登录页。
  A clear "disconnected, retrying" bar and auto-reconnect.
- 悬停链接时预先加载，点开基本是秒出；滚动条、字体在三个平台上统一。
  Prefetch on hover; consistent scrollbars and fonts on all three OSes.
- 5 万条运行记录下，任务列表和首页从约 450ms 降到 2ms 以内；API 返回压缩后小了约 80%；已结束的日志压缩保存；桌面托盘空闲时基本不再查库。
  Much faster lists with many runs, gzipped API, compressed old logs, a quieter tray.

Windows, AppImage and server-tarball installs of 0.1.7 get this update in-app; macOS 0.1.7 needs the one-time manual install described at the top.
