# v0.2.7

## 中文

修复点击「会话」后页面卡在骨架屏，并拖住其他页面的数据库死锁。

- 会话列表先完整读取并释放 SQLite 查询结果，再解析技能、能力包名称和显示币种。避免在单连接数据库上等待自己持有的连接；已有会话、绑定、消息和费用记录保持兼容。
- 会话详情在打开消息结果集前准备显示币种；会话读取失败或取消后立即返回，不再继续查询展示信息。
- 普通 GET 和显式标记为只读的 RPC 请求（含预取）统一使用默认 30 秒超时。失败后显示重试入口；写入和长任务仍保留原有超时语义。
- 增加真实 SQLite 单连接回归，覆盖技能与能力包绑定、多会话、缺失绑定、冷缓存、读取失败和取消后的连接释放。此前仅靠前端超时无法解除数据库自锁；本次修复服务端根因。
- 本次没有新增数据库迁移或模块依赖。

## English

Fix a database deadlock when opening Sessions that could leave the page on a skeleton and block other pages.

- Read and release the SQLite session result set before resolving skill/capability names and display currency. This avoids waiting on the same connection held by the list query, while preserving existing sessions, bindings, messages, and costs.
- Prepare display currency before opening the session-turn result set. Return immediately when a session read fails or is canceled.
- Apply the default 30-second deadline to GET requests and explicitly read-only RPCs, including prefetches. Failed reads offer retry; writes and long-running operations retain their existing timeout behavior.
- Add real single-connection SQLite regressions covering bindings, multiple sessions, missing bindings, cold caches, read errors, cancellation, and connection release. The previous client deadline could not resolve the database self-deadlock; this release fixes its server-side cause.
- No database migrations or module dependencies were added.
