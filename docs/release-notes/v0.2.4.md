# v0.2.4

## 中文

这次补丁集中整理预算、任务时限与界面交互，并修复 macOS 会话后台进程的重复 Dock 图标问题。

- **统一每日预算**：只保留一个全局每日金额上限，覆盖会话、任务、辅助、优化和灰度运行。移除全局 Token 限额和分类每日预算；任务级金额/Token 控制、费用模式、服务商配额、用量统计继续保留。
- **集中预算入口**：在「设置 → 预算」管理金额、超限动作和提醒阈值；花费页保留统计和设置入口。
- **执行时间按需限制**：新任务默认不限时。勾选「限制最长执行时间」后填写 1–1440 分钟；获得执行槽后才开始计时，不包含排队。到时只停止本次运行，不改任务开关。已有正数时限和旧版本中省略的时限配置继续保留。
- **macOS 后台进程**：修复桌面入口未分发会话 MCP 与凭据头命令而进入 GUI 启动的问题；守卫、插件、会话工具改用随应用打包的无界面辅助程序。
- **界面一致性**：整理分区导航、会话留白、下拉控件和模型可用性，修复网络设置的测试/保存按钮对齐。
- **外部工具授权**：调整授权弹窗的文字、留白、分组和长内容显示，明确能力、会话访问范围与授权操作。

### 升级与兼容

升级前建议备份数据库。迁移 042 仅清理废弃的分类预算配置和全局 Token 限额，保留全局金额/动作/阈值、任务预算、历史账本和用量统计。旧客户端提交已移除的预算种类会收到明确错误，不会重新启用限制。明确设置为跳过预算的任务仍按既有模式运行并计入花费。

无执行时限的任务仍可手动停止，仍受费用、权限、服务商配额及任务状态检查约束。已有任务不会因为升级自动解除原有正数时限。macOS 应完整替换应用包，勿只替换主可执行文件，以免缺少新的辅助程序。

## English

This patch simplifies budgets and task time limits, improves interface consistency, and fixes macOS session subprocesses opening a second desktop application.

- One shared global daily monetary budget replaces the global token cap and category-specific daily budgets. Task controls, accounting, provider quotas, and explicit budget bypass modes remain available.
- Global amount, breach action, and warning threshold are managed together in Settings → Budget; Spend links to that single editing location.
- New tasks are unlimited by default. Enable the execution-time checkbox to set 1–1440 minutes. The clock starts after queue admission and only stops the current run. Existing positive limits and legacy omitted fields are preserved.
- All executable entry points now dispatch session MCP, capability headers, guard hooks, and built-in workers consistently. macOS packages include a separate headless helper.
- Section navigation, conversation layout, selects, available-provider filtering, network buttons, and external-tool authorization dialogs are more consistent and readable.

Back up the database before upgrading. Migration 042 removes obsolete budget configuration only; task budgets and historical usage remain intact. Replace the complete macOS application bundle so its new helper is installed. Unlimited tasks remain cancellable and subject to their other controls.
