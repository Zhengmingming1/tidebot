# tidebot v0.1.4

## 修复 / Fixes
- **macOS 找不到 Claude Code**：现在会通过登录 shell 和常见安装目录（nvm/fnm/asdf/mise、Homebrew、npm、bun、volta、pnpm…）查找 `claude`，并逐个用 `--version` 验证；npm 安装时会让 node 可用。状态弹窗会显示“通过什么方式找到的”，找不到时列出搜索过的路径。也可以手动填路径（桌面版带文件选择器），点“重新检测”立即生效。
  Claude Code is now found on macOS via your login shell and common install dirs; the popover shows how it was found (or where it looked), and you can set the path manually.
- **页面切换闪烁**：切页面、切标签不再闪骨架屏，保留滚动位置，没有布局跳动（自动化检查：27 次切换中有闪烁的从 13 次降到 0 次）。
  No more flicker when switching pages/tabs.

## 新东西 / New
- 新的应用图标和托盘图标（macOS 用模板图标，跟随明暗模式），Windows exe 也带上了图标。
- 设置 → 服务商重新设计：卡片列表、新的“添加服务商”卡片墙（分类、搜索、键盘操作）、带分区和固定底栏的编辑抽屉。
- 界面图标统一换成 Lucide。
- README 截图全部重拍。
