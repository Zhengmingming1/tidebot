# tidebot v0.1.10

本版集中改进三主题界面、动态海浪标识和窗口缩放体验，并修复 Claude 查找测试的环境隔离。

## 界面与使用体验

- 石墨、潮汐、午夜共用新版工作区，每套保留浅色、深色和跟随系统。
- 首页可直接输入提示词快速运行；与完整运行表单、快捷键入口共享草稿。
- 任务详情增加可收起的任务列表、搜索与筛选；切换页面和调整窗口大小保留需求草稿。
- 运行详情采用最终回答、日志、答案对比页签和可折叠检查器，区分本次运行版本与任务当前配置。
- 切换日志页签时保持连接和阅读位置，后台新输出不会把用户读到的位置重置。
- 更新为蓝色卷浪 logo，保留运行加速、隐藏暂停和减少动态效果支持；应用、favicon 和各平台托盘图标同步更新。
- 窗口宽度变化时导航和辅助栏自动收展；窄屏工具栏换行，宽表格在自己的区域滚动，低高度窗口可纵向滚动。

## 修复与验证

- 隔离 Claude 路径查找测试，避免本机已有安装影响测试结果；真实 Homebrew/npm/nvm 查找行为保持不变。
- 修复跨入口草稿同步、最近提示词回填、任务栏状态刷新及检查器空需求状态等边界。
- 根模块与桌面模块测试、静态检查及三系统 CI 通过。
- 浏览器验证覆盖三主题六配色、中英文、320–1920 像素宽度的 64 个页面组合和连续缩放操作。
- 现有任务、版本、预算和主题偏好保持兼容；本版没有新增 Skill 创建功能。

## English

This patch refreshes all three themes and the home, task, and run workspaces. It adds adaptive navigation and auxiliary panes, preserves drafts and log reading positions, and updates the animated wave branding and platform icons. Existing tasks, versions, budgets, and theme preferences remain compatible.

Claude executable discovery tests are now isolated from machine-local installations without changing production discovery. Core/desktop tests and the three-platform CI pass; browser checks cover light/dark themes, English/Chinese, and 320–1920 px layouts.
