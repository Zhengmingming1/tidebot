# tidebot v0.2.3

本次小版本汇总会话、能力包与任务预算控制的更新。

## 新增与改进

- 新增会话页面，可新建只读会话、从已结束运行继续对话，并按轮查看进度与费用；支持绑定技能和能力包，从下一轮生效。
- 能力包支持发现、安装审查、依赖预检、绑定、版本更新与回退、导出、快照清理和卸载；外部工具需按发现的精确名称单独授权。
- 远程 MCP 支持经过确认的 OAuth 连接；凭据按组件隔离，卸载与断开授权、清除凭据分开操作。
- 任务新增「任务限制」「仅全局限制」「绕过预算」三种费用策略，支持 USD/CNY 显示与过期编辑保护。绕过预算需要明确确认，不代表免费使用，仍记录费用。
- 调整小窗口工作流编辑器布局，并更新 Tide T 品牌图标。

## 安全与兼容

- 运行禁止修改 agent 配置，使用严格 MCP 配置；未绑定的插件 MCP 不会进入运行，临时配置用完删除。
- 加强能力包路径、依赖、版本和生命周期保护，修复 macOS 与 Windows 路径校验兼容性。
- 升级前备份 Tidebot 数据目录和 SQLite 数据库。包含数据库迁移及旧任务预算值的显式化；完整回退应同时恢复升级前数据库与旧二进制。
- 默认只读会话不等于所有第三方能力都已获准执行。下载依赖、外部工具、联网和付费测试仍按界面要求分别确认。
- 可选 OCI 执行与操作系统级网络沙箱尚未启用。测试通过不等于第三方服务和真实模型端到端验收。

## English

This patch adds read-only chat sessions and continued conversations, reviewed capability-package lifecycle workflows, scoped MCP authorization, and per-task cost policies with currency-aware editing. It also improves compact workflow layouts and cross-platform path validation. Back up the data directory and SQLite database before upgrading; rollback requires the previous database and binary together. Budget bypass remains metered, and third-party tools and paid tests still require their own approvals.
