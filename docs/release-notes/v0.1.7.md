# tidebot v0.1.7

这一版攒得比较多，大部分是“用起来顺手”的改动。

## 运行 / Runs
- **运行可以停了**：跑着的点“停止”确认后结束，排队中的直接移出队列。排队的运行会显示排在第几个，命令行是 `agentctl runs stop --id <运行 ID>`。
  Stop a running run, or drop a queued one; queued runs show their place in line.
- **重跑和改后重跑**：运行详情页一键重跑；快速运行还能带出原来的提示词和服务商，改完再跑（`e` 键直达），也能直接存成定时任务。
  Rerun from the run page; edit-and-rerun a quick run, or save it as a task.
- **快速运行更顺手**：最近用过的提示词以小标签列出，记住上次的服务商，Ctrl+Enter（Mac 上 ⌘+Enter）直接跑。快速运行和新建任务的提示词会自动存草稿，关掉弹窗、刷新、重新登录后都还在。
  Recent prompts, remembered provider, Ctrl/⌘+Enter, and prompt drafts that survive a reload.
- **实时日志真的实时了**：改成写入即推送，新输出的延迟从大约 360ms 降到 17ms 左右。复制、下载、全屏挪到标题栏，筛选栏不再折行。
  Live logs are pushed on write (~17 ms instead of ~360 ms); log actions moved to the title bar.
- 退出时会等正在跑的任务收尾，然后记成“已停止”；崩溃后遗留的运行下次启动会被正确关掉。启动前一刻停止或退出也不会再被误记为失败。
  Graceful quit, orphaned runs closed after a crash, and no more false "failed" when stopping right before start.

## 花费 / Spend
- **按模型算钱**：按实际 Token 用量、用各自模型的价格计费，不再一律按 Claude 官方价估算；订阅套餐只记 Token。价格表每周自动同步一次（签名的价格目录），来源和更新时间收在“设置 → 价格目录”里。
  Runs are priced per model from token usage; the price catalog syncs weekly.
- 运行中每 5 秒存一次用量，进程崩了也不丢账；运行详情实时显示已经花了多少。
  Usage is saved every 5 s during a run; run details show spend live.
- 排队的运行轮到它时再查一次预算：排队期间预算用完或任务被暂停就跳过，原因会写清楚。
  Queued runs re-check the budget when they get a slot.
- 花费图每天都有刻度和网格线，可以把选中时间段导出成 CSV（带 BOM，Excel 直接打开不乱码）。
  Cleaner spend chart and CSV export.

## 界面 / UI
- 弹窗有没保存的修改时，Esc、点外面、关闭、返回前会先问一句；弹窗标题和按钮固定，1024×655 的窗口也放得下。
  Dialogs ask before discarding unsaved changes and fit a 1024×655 window.
- 技能能下载成 .zip（列表、详情、任意版本都行），拿到另一台电脑直接导入。
  Download any skill version as a .zip.
- 新建任务时根据提示词自动填名字和定时、建议每日预算；加服务商时粘贴 Base URL 或一段环境变量就能认出来；按钮表单会推荐图标；官方插件会用你已有的设置预填。
  More forms fill themselves in.
- 复制任务（生成一份暂停中的副本，可撤销）。浏览器标签页图标上有运行中 / 失败的小角标。
  Duplicate a task; tab icon badges for running and failed runs.
- 运行列表一行一条，ID 和计划细节收进悬停提示，页面更清爽；首页和运行列表只在有变化时才刷新。
  Tidier runs table and pages; lists only re-render when something changed.
- “设置 → 数据与备份”能看到占用空间、改保留天数、预览清理内容、压缩数据库；磁盘快满时会提醒。
  Storage overview, retention settings, clean-up preview, low disk warning.
- 桌面版导出和保存走系统的保存对话框，存完可以“在文件夹中显示”，也能直接打开数据文件夹。
  Desktop: native Save dialog, "Show in folder", open the data folder.
- WebUI 静态资源按内容哈希缓存并 gzip 压缩，再次打开不用重新下载约 640 KB。
  Static assets are cached by content hash and gzipped.
- 1024 宽的窗口里，版本树不再被放大，英文界面的日志筛选栏也不再折成两行。
  Version tree and English log filter bar fixed at 1024 px wide.

## 开源和安全 / Open source & security
- 源码以 GNU AGPL-3.0-only 开源了：https://github.com/Zhengmingming1/tidebot 。安装包和自动更新照旧走 tidebot-releases。
  The source is now public under AGPL-3.0-only.
- 升级到 Go 1.26，并升级 x/crypto、x/net，修掉了标准库和依赖里的已知漏洞。
  Go 1.26 plus x/crypto / x/net updates for known vulnerabilities.
- 发布流程加固：签名密钥只在受保护的环境里可用，第三方 Action 全部钉到提交哈希；CI 每次提交都在 Linux / macOS / Windows 上跑，并用 gitleaks 扫描完整历史。自己从源码编译的版本只提示新版，不会被自动替换成官方包。
  Hardened release pipeline, 3-OS CI on every push, gitleaks; self-built copies are notify-only.

0.1.6 会自动收到这次更新。更早的版本如果一直没有提示，到 https://github.com/Zhengmingming1/tidebot-releases/releases/latest 手动下载一次就好。
If you're on 0.1.6 it updates itself; older versions that never show the update can grab it from the releases page once.
