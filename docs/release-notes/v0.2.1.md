# tidebot v0.2.1

本次补丁版汇集 v0.2.0 之后的功能与稳定性改进：新增 Skill 仓库、技能包依赖与维护工具、初始上下文规划，并修复执行、页面和 CI 的边界问题。

## Skill 仓库

- 在「技能 → Skill 仓库」添加 GitHub、GitLab、Gitee 或公司自建 Git 的 HTTPS/SSH 克隆地址，选择分支、标签及扫描目录。
- 递归发现 `SKILL.md`，按名称、说明或路径搜索，预览文件树后单项或批量安装完整技能目录。不同来源的同名技能不会自动覆盖。
- 来源绑定记录仓库、目录与固定提交。检查更新只比较该技能的内容；先获取新版本，再查看差异与引用影响，明确采用。已有本地修改与过期预览不会被静默覆盖。
- 保留版本回退和独立副本。移除仓库或远端目录不会卸载本地技能；扫描可取消，失败保留上次成功目录，缓存可单独清理。

## 技能包、预检与对照评测

- `tidebot.json` 可声明必需/可选技能依赖、内容摘要约束和环境要求；在本地技能库中递归查找候选，预览后明确采用，不自动下载或安装依赖。
- 技能组合增加用途说明、输入输出提示与最多 5 个文本验收样例，随不可变版本及 ZIP 保存。说明用于帮助使用者，不会自动变成模型指令。
- 新增不调用模型的本地预检，区分已找到、缺失、目标环境禁用和待核实。AI 静态分析仍需单独发起并计费，不覆盖程序确认的结果。
- 任务和工作流节点可追踪来源组合版本，预览升级影响后明确采用或回退；并发版本校验保护其他页面和本地已修改的绑定。
- 可对同一输入分别运行主技能与完整组合，记录文本断言、输出、耗时、费用及子运行。评测固定版本和模型，可取消，重启后保留中断状态，不自动重放或采用结果。
- 运行详情增加实际技能快照的 `loaded` 证据；它表示运行材料已提供，不证明模型实际读取或使用了每个技能。

## 上下文与执行可靠性

- 新增确定性 Context Planner：按技能版本、内容摘要和来源去重，检查数据作用域与初始输入预算，并记录执行前计划。必需材料超预算时明确拒绝，不截断安全指令。
- 工作流节点可选择祖先输出的完整原文、规则摘录或引用模式。重复引用只装载一份材料，保留来源和原文追溯；已有未开启规划的工作流保留内联模板方式。
- 减少重复的技能绑定、依赖与上下文读取；在分配最终提示词前检查展开大小，避免超限输入造成大块临时内存分配。
- 调度任务原子领取，daemon 恢复失败时拒绝启动并释放资源；修复运行开始前取消、后台任务退出等待、评测恢复归属及晚到回调问题。
- 工作流节点增加默认关闭的瞬态错误重试与可取消退避，执行器异常转为失败。仅应对可幂等操作开启重试；不保证外部副作用只发生一次。
- 增加执行队列、耗时、失败、取消及重试诊断指标；结果缺失、输出超限和状态持久化失败会明确报告。

## 页面、安全与测试修复

- 页面加载失败显示错误及重试入口，不再被骨架屏遮住；已离开页面的迟到失败不会覆盖当前页面。
- 技能组合和工作流错误按界面语言显示，历史执行记录中的已知错误也可翻译。
- 加强插件授权与撤销后的凭据处理、日志脱敏、MCP 并发关闭，以及 Skill 导入路径、普通文件类型和大小限制；覆盖 Windows 保留文件名与路径别名。
- WebUI 源码和 API 按功能拆分，保留原有资源与接口；CI 校验生成文件、双语键、三平台构建、性能基准与全量 race。
- 修复 MCP 测试读取竞态、排队状态断言时序及事件流跨分钟误报。事件流仍会按分钟刷新；测试分别检查数据写入计数、通知和运行状态。

## 升级与使用边界

- 从 v0.2.0 升级后，首次启动自动应用新增迁移 **030–032**：运行来源、对照评测、仓库与技能来源绑定。旧技能、无依赖清单的包及已有任务继续保留；旧记录不补造加载证据。
- 升级前保留应用数据备份。二进制回退不会自动回滚数据库；需要降级并继续编辑数据时，使用升级前备份。
- 使用仓库功能需要在 **Tidebot 服务进程所在机器和账号** 下安装 Git，并配置所需凭据、SSH agent、证书及网络。不会自动安装 Git 或跳过服务器身份校验。
- 浅克隆可能获取仓库当前快照中的未选文件对象，每仓库缓存上限为 256 MiB。首版不自动补齐目录外资源，不支持符号链接、子模块及 LFS 指针导入，也不保留脚本执行权限位；导入不会启用插件 hooks/MCP 或安装运行依赖。
- 所有新运行增加初始上下文预算检查；默认输入上限为 65,536 个估算 Token，技能正文仍有 256 KiB 限制。Token 是估算，规则摘录是有损处理，不能替代供应商精确计数或约束外部 runtime 的后续模型轮次。
- 对照评测仅允许 `Read`、`Glob`、`Grep`，关闭全部 MCP。文本断言通过不代表业务结果正确或完整组合质量更高；需要外部系统和脚本的技能仍需另行验收。

## 验证范围

- 发布前源码基线 [825bd77](https://github.com/Zhengmingming1/tidebot/commit/825bd7763ddbd94a91afa7d0c6c2e566ce4d2bad) 的 [CI 10 项全部通过](https://github.com/Zhengmingming1/tidebot/actions/runs/41570667074)，包括三平台核心与桌面检查、Linux Go 1.26/1.27、全量 race、签名自更新端到端测试、生成文件和密钥扫描。
- 本地全量 race 与事件流相关 30 轮回归通过。真实公共 GitHub 仓库已完成扫描、完整目录读取，以及浏览器添加、预览、安装与来源核对。
- 私有仓库、SSH、GitLab、Gitee 和公司内网环境尚未实测；真实模型、MCP 与第三方脚本的端到端效果未作完整验收。上述源码验证不代替安装包在目标机器上的运行验证。

## English

This patch release includes the improvements completed after v0.2.0. Add HTTPS/SSH Git repositories, discover skills, preview and install selected directories, and track their sources. Updates are downloaded before explicit adoption; name collisions, local changes and stale previews cannot silently replace existing skills. Removing a repository keeps installed versions.

Skill sets gain dependency manifests, local preflight checks, documentation, version-aware upgrade previews and paid comparison evaluations. Deterministic context planning scopes and budgets the initial input, deduplicates repeated upstream material and records an audit. Execution recovery, cancellation, scheduling, optional workflow retries, plugin permissions, import validation, UI errors and translations are also improved.

Migrations 030–032 run at startup. Back up application data before upgrading; binary rollback does not roll back the database. Repository access requires Git and credentials on the Tidebot host. Preflight does not install dependencies, and restricted text evaluations do not validate external services. The source CI matrix and local full race checks pass; public GitHub HTTPS installation was verified, while private repositories, SSH and other Git hosts still need environment-specific validation.
